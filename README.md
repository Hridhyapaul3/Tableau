# 📊 Indian Superstore – Tableau Visualization Project



## 🌟 About the Project

This project explores the **Indian Superstore** dataset using Tableau. It presents retail data through a collection of visualizations that help explore sales, profit, products, customers, and regional performance.

The packaged Tableau workbook includes **28 worksheets**. The checklist below uses the worksheet names saved in the workbook.

## 🧰 Tools Used

- **Tableau** – Data visualization and analysis
- **Indian Superstore Dataset** – Retail orders data

## 🎯 Project Goals

- Explore sales and profit patterns.
- Compare product and category performance.
- Examine geographic and regional trends.
- Present retail information through different chart types.
- Practice building clear and informative visualizations in Tableau.
